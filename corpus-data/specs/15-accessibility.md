# 可访问性与国际化规范

## 语义化与键盘

- 优先使用语义化标签（button、nav、header）；禁止 div/span 模拟可交互控件。
- 所有可交互元素必须可键盘操作，焦点顺序与视觉顺序一致。
- 自定义下拉、弹层等组件必须实现基本 ARIA 模式：`role`、`aria-expanded`、`aria-selected`。
- 弹窗打开时锁定焦点于弹窗内，关闭后焦点归还触发元素。

## 内容可读性

- 图片必须提供有意义的 `alt`；装饰性图片使用空 alt。
- 文本对比度不低于 WCAG AA（4.5:1）；禁止仅用颜色传达状态，需伴随图标或文案。
- 表单控件必须关联 label；错误提示通过 `aria-describedby` 关联并支持读屏播报。

## 国际化

- 面向用户的文案禁止硬编码，一律通过 i18n 词典 key 引用。
- key 命名按域分层：`order.list.title`；禁止中文拼音 key 与整句拼接翻译。
- 包含变量的文案使用带占位符的完整句式，适配语序差异；复数使用复数规则。
- 时间、数字、货币格式化统一走 Intl API，禁止手工拼接格式。

## 适配

- 支持浏览器字号放大（rem 布局）不破版。
- 动效遵循 `prefers-reduced-motion`，必要时降级为直接切换。
