# CSS 编写规范

## 样式隔离

- 组件样式必须使用 scoped 或 CSS Modules，禁止全局裸写组件样式。
- 全局样式仅允许出现在 `styles/` 目录下的 reset、变量、工具类文件中。
- 深度选择器使用 `:deep()`，禁止 `>>>` 与 `/deep/` 旧语法。

## BEM 使用细则

- 一个组件是一个 block，内部元素用 `__`，状态修饰用 `--`。
- 不允许跨 block 直接嵌套选择器超过两层，需要联动时由外层传状态类。
- 修饰类必须伴随基类同时存在：`class="btn btn--primary"`，禁止只写 `btn--primary`。

## 单位与响应式

- 字体、间距优先使用 rem 或设计令牌变量；边框 1px 场景允许 px。
- 断点统一在变量文件定义：`$bp-sm: 640px`、`$bp-md: 768px`、`$bp-lg: 1024px`，禁止魔法数字。
- 移动端优先书写媒体查询，使用 `min-width` 向上适配。

## 禁止事项

- 禁止使用 `!important`，第三方库覆盖场景需注释说明并在评审时报备。
- 禁止使用 `*` 通配选择器做业务样式（reset 除外）。
- 禁止内联样式承载布局逻辑，仅允许动态计算值（如拖拽坐标）。

## 样式文件组织

- 设计令牌（颜色、字号、间距、阴影）统一收敛到 `styles/tokens.css`，组件内禁止硬编码色值。
- 主题色、语义色必须使用变量引用，便于暗色模式与换肤。
