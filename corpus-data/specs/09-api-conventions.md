# 接口调用规范

## 请求封装

- 所有请求必须经过统一 request 实例：注入 baseURL、超时、鉴权头与错误拦截。
- 禁止在组件中直接使用原生 fetch/axios 裸调业务接口。
- 超时时间统一 10s，文件上传等特殊场景显式覆盖并说明。

## 错误处理

- 业务错误码在拦截器统一映射：登录失效跳转、提示语、重试策略。
- 组件层只处理页面级兜底（空态、失败重试），不重复处理全局错误。
- 静默失败的请求必须注释说明原因。

## Loading 与防抖

- 页面级请求使用统一的 loading 状态；局部操作使用按钮级 loading，防重复提交。
- 搜索输入必须防抖（300ms）；表单提交必须防重（禁用或幂等）。

## 请求取消与竞态

- 路由切换/组件卸载时必须取消未完成请求（AbortController）。
- 同一接口的连续调用（翻页、筛选）必须处理竞态：丢弃过期响应或取消旧请求。

## 类型定义

- 每个接口显式定义请求参数与响应类型，响应体遵循统一信封：`{ code, data, message }`。
- 列表接口响应统一 `{ list, total }` 结构，分页参数统一 `pageNum / pageSize`。
- 枚举字段（状态、类型）必须定义联合类型或 const 映射，禁止裸 number 判断。
